# Vibrex 코인 블록체인 연동 설계 (v1 — 상장 준비 단계)

## 0. 결정
- **온체인 대상 코인 = 게임 코인(VC)**. 프롬코인은 LLM 원가와 직접 연동되는 *서비스 크레딧*(선불·환불 대상)이라 증권/전자화폐 규제 리스크가 크고, 게임 코인은 플레이·팁·광고 예산·후원 등 **플랫폼 내 유틸리티**로 쓰여 토큰화에 적합.
- 토큰명(가칭) **VIBREX (VBX)**, 표준 **ERC-20**, 체인 **Base**(L2, 수수료 낮음·코인베이스 생태계·상장 경로) — 필요 시 Polygon 미러.
- **1단계(지금~상장 전): 오프체인 원장 + 해시체인 + 커스터디얼.** 앱은 프라이빗 키·서명·지갑 SDK 를 **일절 포함하지 않는다**(해킹 표면 최소화). 온체인 발행/출금은 별도 격리된 트레저리 서비스(멀티시그)에서만.

## 1. 원장(Ledger) — 이미 구현
- `game_coin_ledger`: `profiles.vcoin` 이 바뀔 때마다 트리거가 **append-only** 로 기록. 각 행 `hash = sha256(prev_hash | user | delta | balance | ts)` → 해시체인. `game_coin_ledger_verify()` 로 훼손 지점 탐지. UPDATE/DELETE 권한 회수.
- 관리자 *보안·서버* 메뉴에서 무결성 상태·최근 해시 확인.
- 다음 단계: 하루 1회 최신 해시를 온체인(Base) 컨트랙트 `anchor(bytes32)` 로 기록 → 원장 조작 불가 증명(공증). 비용 ≈ 월 $1 미만.

## 2. 토큰 설계(토크노믹스 초안 — 상장 심사 대비)
- 총 발행 1,000,000,000 VBX (고정, 민팅 불가 / 소각 가능).
- 배분(예): 커뮤니티·플레이 보상 40% · 팀 15%(4년 베스팅, 1년 클리프) · 트레저리/생태계 20% · 유동성 10% · 초기 투자 10% · 어드바이저 5%.
- **오프체인 VC ↔ VBX 1:1 스냅샷 전환**: 상장 시점 원장 잔액을 기준으로 클레임(지갑 연결 + 서명 검증) → 클레임 컨트랙트(머클 트리)로 배분. 이후 신규 VC 는 계속 오프체인(빠름·무료), 출금 시에만 온체인.
- 인플레 억제: 플레이 보상은 광고 수익·결제 수익의 일정 비율(예 30%)로만 발행(백킹).

## 3. 아키텍처
```
[앱/DB(Supabase)] --원장 해시--> [Anchor 서비스(격리 VM, KMS)] --tx--> [Base: Anchor 컨트랙트]
[사용자 지갑 연결] --서명(EIP-4361 SIWE)--> [앱 검증 후 wallets.verified=true]
[출금 요청] --DB 큐--> [Treasury 서비스(멀티시그 Safe, 일일 한도)] --transfer--> [사용자 지갑]
```
- 앱 서버는 **RPC 읽기 전용**(잔액 조회)만. 쓰기(민팅/전송)는 앱에서 불가.
- 출금 정책: KYC(한도 초과 시), 24h 지연, 일일 한도, 관리자 승인, 이상 탐지 시 자동 홀드.

## 4. 해킹 요소 제거 체크리스트 (앱 측)
- [x] 프라이빗 키·니모닉·서명 라이브러리 미포함 (web3 지갑 SDK 도입 시 `viem` 만, 버전 고정, 읽기 전용)
- [x] Service Role 키 서버 전용, RLS 전 테이블, 원장 append-only
- [x] 결제 웹훅 서명 + 발신 IP 허용목록, IP 원문 미저장(해시)
- [x] 관리자 조치·서명 실패·비허용 IP 를 `security_events` 로 기록, 이상 트래픽 감지(세션/해시IP)
- [ ] 출금 API 는 상장 단계에서 별도 서비스로 — 앱에 넣지 않음
- [ ] 스마트컨트랙트: OpenZeppelin ERC-20 + 감사(2곳) 후 배포, 업그레이더블 금지, 오너 키 멀티시그(3/5)

## 5. 규제 메모
- 국내 가상자산이용자보호법·특금법: 국내 거래소 상장은 VASP 요건, 해외 상장(Base 생태계·DEX→CEX) 경로 우선.
- 게임 코인의 현금화가 붙는 순간 사행성 심의(게임산업법) 이슈 → 초기엔 **플랫폼 내 유틸리티 + 클레임/출금은 해외 지갑**으로, 법률 검토 후 확대.

4. 스냅샷 클레임 · DEX 유동성 · CEX 상장 신청
